# 订阅回归样本

每个 `.yaml` / `.json` / `.txt` 文件是一份**脱敏后**的真实订阅（KongPrism › 诊断连接 › “导出脱敏样本”生成）。
测试会逐个检查：能解析出节点、不是“访问受限”占位、生成的配置能通过真实 sing-box 的 `check` 且没有节点被内核拒绝。

`refused-placeholder.yaml` 例外：它是机场拒绝客户端时返回的占位内容，测试要求它被识别为“拒绝”。

问题报告（菜单 › 生成问题报告）里的 `节点结构（已脱敏）.json` 也可以直接放进来：它来自本机缓存的节点，订阅暂时下载不了时也有。

`panel-trojan-colon-names.yaml` 按 2026-11-11 用户问题报告里的节点命名还原（服务器、密码为虚构），覆盖名称里不加引号的“流量倍率:0.2”和“有效期…, 剩余…”信息条目。
